◆ FileType

enum qTbot::IBot::FileType

The FileType enum is a list of file types. It defines how a file should be downloaded - as a local object in the file system or into virtual memory.

Enumerator
Ram 

Ram virtual file type. All file data will be saved into a QFuture bytes array.

Local 

Local file type. The file will be saved in the internal file storage. This file type can use the file system as a cache and will download a file with the same id only one time.
